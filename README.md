# Department of Defence PNG Position Vacancies Website

This folder is ready for GitHub Pages upload.

## Main files

- `index.html` — homepage
- `vacancies_by_divisions.html` — vacancy register with 313 positions across 9 divisions
- `success.html` — success page
- `README.md` — project instructions
- `.nojekyll` — helps GitHub Pages serve static files normally

## Application link

All Apply / Apply Online / Submit Another Application buttons are configured to open:

https://form.jotform.com/261105229819861

## Upload to GitHub

1. Extract this ZIP file.
2. Open your GitHub repository: `dod-position-vacancies`.
3. Click **Add file > Upload files**.
4. Upload/replace these files in the repository root:
   - `index.html`
   - `vacancies_by_divisions.html`
   - `success.html`
   - `README.md`
   - `.nojekyll`
   - `logo.png` and `background.jpg` if you have them
5. Click **Commit changes**.

## GitHub Pages

Go to:

**Settings > Pages > Deploy from a branch > main > / root > Save**

Your site should be available at:

https://depaulkuyama-tech.github.io/dod-position-vacancies/
